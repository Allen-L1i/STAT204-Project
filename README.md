# Predicting household appliance energy use

A reproduction and extension of the appliance energy analysis by Candanedo et al. (2017) for STAT 204 (UC Santa Cruz, Fall 2026).

**To run it, open [`run-analysis.qmd`](run-analysis.qmd) and follow it.** In short:

1. Open this folder in Positron (*File → Open Folder*).
2. In the R console: `renv::restore()`
3. In the terminal: `quarto render run-analysis.qmd`

The rendered `run-analysis.html` explains each step of the analysis.
The dataset and original R code come from [the authors’ repository](https://github.com/LuisM78/Appliances-energy-prediction-data).

**Running a single step?** Run the corresponding script in [`Code/`](Code/) from the project root.
